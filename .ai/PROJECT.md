# PROJECT — 要件と方針の SSOT

> `.ai/BRIEF.md` および Google Maps共有リストをもとに整理した要件定義書。（2026-09-03 富山サウナ5選追加）

---

## 1. 目的

大学同期の男性4名で行く「福井・富山 2泊3日レンタカー周遊旅行（2026/9/20〜9/22）」に向けて、Google Maps保存リスト（メンバーのコメント・理由付き）を集約し、日中のドライブ＆観光と夕方以降のサウナ＆夜飲みを最適化させたWeb旅程表・栞（しおり）を構築・GitHub Pages公開する。

---

## 2. 確定スケジュール・交通・宿泊仕様 (SSOT)

### 交通・タイムライン

- **往路新幹線**: 9/20(土) 東京 08:11発 ➔ 福井 11:09着（かがやき505号・9号車）
- **レンタカー貸出**: 9/20(土) 11:30 トヨタレンタカー **福井駅東口店**（福井市日之出2-2-18 / TEL: 0776-24-0100）
- **レンタカー返却**: 9/22(月・祝) 16:00 トヨタレンタカー **富山駅前店**（富山市宝町1-1-7）
- **復路新幹線**: 9/22(月・祝) 富山 17:29発 ➔ 東京 19:48着（北陸新幹線）
- **レンタカー車両**: C3クラス 1台 禁煙 AT (総額: 45,697円 現地決済)

### 宿泊

- **1日目（9/20土）**: アパホテル 福井片町（シングル4室 / 99,000円 現地決済 / **館内天然温泉大浴場＆サウナ完備！**）
- **2日目（9/21日）**: カルフールゲストハウス別館 Airbnb（富山市八日町128-3 / 1棟貸切 / 35,814円 決済済）

## 3. 富山宿（八日町）周辺のサウナ付き温泉 厳選5選

1. **北陸の聖地 スパ・アルプス**（車約12分 / 富山市山室 / 天然水水風呂・北欧ロッキーサウナ・名物サ飯）
2. **Sauna Talo Toyama（サウナタロトヤマ）**（車約18分 / 富山市粟島町 / 北欧ピエニサウナ＆地下水水風呂）
3. **天然温泉 海王**（車約18分 / 射水市鏡宮 / 地下1200m黄金温泉 ✕ METOS ikiサウナ・熱波ロウリュ）
4. **越中天然温泉 満天の湯 富山店**（車約12分 / 富山市石金 / 充実露天風呂・遠赤タワーサウナ）
5. **天然温泉 剱の湯（御宿 野乃 富山）**（車約12分 / 富山市総曲輪 / 自家源泉黒湯天然温泉・高温ヒノキサウナ）
